<objective>
Convertir la tab "Alhajas" hardcodeada en plazos-periodos en un conjunto de tabs dinámico derivado de `selectedPlazo.tiposPrenda`. Cada tipo de prenda asignado al plazo produce una tab; solo la tab de Alhajas conserva el contenido actual (tabla de hechuras, recálculo, agregar). Las demás (Plata, Varios, Autos/Motos, etc.) muestran un placeholder hasta que se implemente su detalle.

Purpose: Eliminar el bug donde "Alhajas" se mostraba siempre, incluso para plazos asignados a otros tipos de prenda. Es la base para futuros detalles por tipo (Plata, Autos/Motos).
Output: Componente refactorizado (ts + html), build limpio, comportamiento verificado manualmente.
</objective>

   ```typescript
     const tipos = this.selectedPlazo?.tiposPrenda ?? [];
     return tipos.map(t => ({
       id: this.normalizarNombreTipoPrenda(t),
       label: t.tipo,
       isAlhajas: this.esTipoAlhaja(t)
     }));
   }
   ```

   ```typescript
   }
   ```

4) Agregar helpers privados:
   ```typescript
   private esTipoAlhaja(tipo: { tipo?: string } | null | undefined): boolean {
     const n = (tipo?.tipo ?? '').trim().toLowerCase();
     return n === 'alhajas' || n === 'alhaja' || n === 'joyeria' || n === 'joyería';
   }

   private normalizarNombreTipoPrenda(tipo: { tipo?: string } | null | undefined): string {
     return (tipo?.tipo ?? '')
       .trim()
       .toLowerCase()
       .normalize('NFD').replace(/[̀-ͯ]/g, '') // quitar acentos
       .replace(/[^a-z0-9]+/g, '-')                       // espacios y / a guiones
       .replace(/^-+|-+$/g, '');                          // trim guiones
   }
   ```
   - Razonamiento: "Autos/Motos" → `"autos-motos"`; "Plata" → `"plata"`; "Alhajas" → `"alhajas"`. Esto produce ids estables y URL-safe para `[ngbNavItem]`.

5) Modificar `cambiarTab(tab: string)`:
   ```typescript
   cambiarTab(tab: string): void {
     this.activeTab = tab;
     this.tabError = '';
     if (tab === 'parametros') {
       this.cargarParametros();
       return;
     }
     if (this.isAlhajasTab(tab)) {
       this.cargarAlhajas();
       return;
     }
     // Tab no-alhajas (Plata, Varios, Autos/Motos...): sin carga por ahora.
   }
   ```
   - NO llamar a `cargarAlhajas()` si la tab no es de tipo alhaja — esa era la raíz del bug.

6) NO tocar la lógica de `cargarAlhajas`, `cargarParametros`, ni el resto del componente.
