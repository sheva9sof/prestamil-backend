# Phase 04.1 Plan 02: Configuración del Oro — Admin UI para tabla de 24 celdas Summary

**Pantalla Angular standalone "Configuración del Oro" con 3 pestañas (Fundir/Normal/Especial), tabla de 8 kilates por pestaña, edición inline del %Prestamo (24K deshabilitado) y campo de precio del gramo de oro 24K, con ruta, mapeo de menú y changeset Liquibase 014 de alta en `opciones`.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 3 completed
- **Files modified:** 9 (6 created, 3 modified)

## Accomplishments

- `oro-config.model.ts` define `OroCeldaResponse`, `OroCeldaUpdateRequest`, `PrecioGramoResponse`, `PrecioGramoRequest` de forma autocontenida (sin importar de `plazo.model.ts`), sin ningún campo `factorFundir/Normal/Especial`.
- `oro-config.service.ts` (`@Injectable({ providedIn: 'root' })`) expone `getTablaOro`, `actualizarCelda`, `getPrecioGramo`, `actualizarPrecioGramo` contra `/api/oro-tabla-prestamo` y `/api/precio-oro` (contratos entregados por 04.1-01).
- `ConfiguracionOroComponent` (standalone, `selector: app-configuracion-oro`) renderiza 3 pestañas vía `ngbNav` (Fundir/Normal/Especial), cada una con una tabla ordenada de 8 kilates (6,8,10,12,14,18,21,24K) mostrando Precio Avalúo (solo lectura), %Prestamo (editable inline salvo 24K) y Precio Prestamo de referencia (solo lectura). La fila 24K se muestra con clase `text-muted`, badge "Referencia (no prendable)" y controles deshabilitados (`[disabled]="!c.editable"`), consistente con ORO-07.
- El campo "Precio del gramo de oro 24K" permite guardar y dispara `actualizarPrecioGramo`, que recalcula todas las tablas en el servidor y recarga la tabla local (`cargarTabla()`).
- Ruta `configuracion/configuracion-oro` registrada en `app-routing.module.ts` (lazy `loadComponent`), y mapeo `'Configuración del Oro': '/configuracion/configuracion-oro'` agregado a `opcionToUrlMap` en `menu-transformer.helper.ts`.
- Changeset Liquibase `014-menu-configuracion-oro.sql` da de alta el submenú "Configuración del Oro" (`opciones.id=16`, `idPadre=6`, bajo Configuración) y lo asigna a los roles Sistemas(1) y Gerente(5) vía `roles_opciones`, registrado en `db.changelog-master.xml` después del include 013.
- `npx tsc --noEmit -p tsconfig.app.json` sin errores tras los tres tasks (exit code 0, verificado contra el checkout compartido real).
- XML del changelog maestro verificado bien formado (`xml.etree.ElementTree.parse`).
